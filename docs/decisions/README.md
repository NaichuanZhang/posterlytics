# Decision records

Every feature gets one decision record at:

`docs/decisions/YYYY-MM-DD-<slug>.md`

Use these sections:

## Backlog item

State the backlog title and the one-line goal.

## Decisions

List every meaningful product, design, and implementation choice.

## Reasoning

For each decision, state why it won over the alternatives considered.

## Follow-ups

List deliberately deferred work and why it remains out of scope. Write `None` when nothing is deferred.

Keep records terse, specific, and honest. Do not restate the implementation without recording the tradeoffs.
